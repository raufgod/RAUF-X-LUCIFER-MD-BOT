# AI reply-chat + voice to AI

## Reply chat (no command again and again)
Send `.gpt hello` once. Now just **reply to the AI's answer** (swipe / long-press > Reply) and the same AI answers again, remembering the last 20 messages.
Reply to the new answer again, and again... Works for every chat AI: gpt, gemini, deepseek, asyntai, talkai, notegpt, zonerai, pollinationai, mathgpt.
- Each AI keeps its own history (replying to a DeepSeek answer talks to DeepSeek, not GPT).
- Replying to a message that is not an AI answer does nothing. A reply starting with `.` is a normal command.
- Answers are remembered for 7 days, also across restarts (`state/ai-replies.json`).

## Voice to AI (needs the user's own Groq key)
- **Reply to an AI answer with a voice note**, or **reply to any voice note with `.gpt`** (or `.deepseek` ...).
- The voice is converted to text by Groq Whisper (user's own key) and the answer is generated by Groq in the background.
- The answer comes back as a **voice note in the Microsoft Edge neural voice** (Hindi for Devanagari, English otherwise, same engine as the welcome voice agent). Very long answers: voice of the first part + the full text. If voice cannot be made, the normal AI text is sent. Set `AI_VOICE_REPLY=text` in `.env` to switch voice answers off.
- Replying to that voice answer (text or voice) continues the chat. Text in -> text out.
- If the user has **no Groq key**, the voice note is NOT processed; the bot tells them how to add one (once per 10 minutes).

### Where the key comes from
1. Website: Link WhatsApp / Create Bot page > "AI API key (optional)". Checked live with Groq, saved only after the number is really linked.
2. In WhatsApp (owner): `.aikey gsk_xxxx` (saves + tries to delete that message), `.aikey` (status), `.aikey remove`.
3. Main bot only: `GROQ_API_KEY` in `.env` is used if no key was saved.
Keys are stored per number in `state/ai-keys.json` (gitignored, never sent to the website).

Optional `.env`: `AI_VOICE_MODEL` (default llama-3.3-70b-versatile), `AI_STT_MODEL` (default whisper-large-v3-turbo).
Test: `node scripts/test-ai-session.js`
Note: it is **Groq** (console.groq.com, gsk_ keys), not xAI's Grok.
