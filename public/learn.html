Guides

Linking The Bot

1) On this website choose your country and type your WhatsApp number without 0 or country code. 2) Tap "Get pairing code" - an 8-character code appears. 3) On the phone: WhatsApp > Settings > Linked devices > Link a device > "Link with phone number instead" > type the code. The code expires in about a minute; get a new one if it expires. The bot then runs on that number. A visitor can request 5 codes per 10 minutes.

Pairing Code Problems

check the country and number are exact (no leading 0); type the code immediately, it expires in ~1 minute; update WhatsApp; WhatsApp allows only 4 linked devices - remove an old one in Settings > Linked devices; if you hit the 5-codes-per-10-minutes limit wait 10 minutes; check your internet; then request a fresh code. If it still fails contact support.

Bot Not Replying

commands start with a dot, e.g. .menu or .ping. Check the bot is still listed in WhatsApp > Linked devices (if it was removed, link again from the website). The bot may be in private mode (owner only) - the owner can send .public. In groups, admin commands (kick, promote, antilink, welcome...) work only when the bot is a group admin. Wait a few seconds and retry.

Menu & Prefix

every command starts with a dot. Send .menu (or .help) to see all commands grouped by category, .ping to test speed, .alive to see if the bot is online, .owner for owner contact.

Songs & Videos

.play <song name> or .mp3 <name> or .song <name> sends audio; you can also paste a YouTube link after the command. .video <name> sends video. .lyrics <song>. .spotify and .spotifydl for Spotify. If it says it could not download, the download service is busy: wait a minute and retry, try a shorter/different name or a direct YouTube link. Very long videos may fail.

Link Downloaders

.tiktok <link>, .instagram <link>, .facebook <link>, .mediafire <link>, .gdrive <link>, .apk <name>, Pinterest photos/videos with .pin <pin link>. Paste the full public link after the command. Private posts cannot be downloaded.

Ai Commands

.gpt, .gemini, .deepseek, .asyntai, .talkai, .notegpt, .zonerai, .pollinationai, .mathgpt (math), .imagine / .imageai for AI images. Each AI remembers the last 20 messages of your chat with it; send ".gpt clear" (same for the others) to start fresh.

Auto Reply (Owner Only)

.autoreply on / off / dm / group / status. In private chats the AI answers every message. In groups it answers ONLY when someone @tags the bot or replies to a bot message. .mentionreply on/off makes the AI answer whenever the bot is mentioned.

Group Tools (Bot Must Be Group Admin)

.antilink, .antibadword, .antitag, .welcome, .goodbye, .tagall, .hidetag, .tagnotadmin, .kick, .promote, .demote, .mute, .unmute, .warn, .warnings, .resetlink, .groupinfo, .setname, .topmembers, .ban/.unban. Use .menu to see the exact options of each.

Stickers & Image Tools

reply to an image/video with .sticker; .stickercrop, .attp (animated text sticker), .emojimix, .take (rename sticker), .simage (sticker to image), .textmaker, .img-blur, .meme, .gif, .wasted. Some tools need you to reply to a photo.

Fun & Games

.joke, .quote, .fact, .trivia, .truth, .dare, .hangman, .tictactoe, .ship, .eightball, .shayari, .compliment, .insult, .flirt.

Mode

the bot is public by default so everyone can use it. The owner can switch with .mode private / .mode public (or .private / .public). In private mode only the owner can use commands.

Safety & Disconnect

the bot is added as a normal linked device, like WhatsApp Web. To remove it: WhatsApp > Settings > Linked devices > tap the session > Log out. Never share your pairing code with anyone. If the bot stops after logging out, link again from the website.

Errors

"Something went wrong / service is busy" means a temporary problem with an online service the command uses. Retry after a minute, try a simpler input, and if it keeps happening tell support which command you used, what you typed, and the time.

Customising (Bot Owner)

.setprefix <symbol> changes the command prefix (1-3 symbols like ! # /), after that use for example !menu; .setprefix . always resets it. .setbotname <name> changes the bot name, .setownername <name> the owner name, .settelegram <https link>, .setwebsite <https link>, .setbotimage (reply to a photo) changes the menu image.

Create Your Own Bot

open Create Bot on this website, enter your bot name, owner name, prefix and optional channel / Telegram / website links and a logo link (https image), you can try a free demo chat first (nothing is sent to WhatsApp), then link your WhatsApp number with the pairing code. Your bot gets its own menu with your name as owner and RAUF × LUCIFER as developer. A private edit key is shown once - save it, because with your number + edit key you can change name, links, prefix and logo later on the same page.

Servers & Docs

on the Link WhatsApp page open the server list and pick any server. The Docs page explains the whole website and every bot feature in detail. All of them connect to the same RAUF × LUCIFER MD BOT bot, so pick any one that is shown online.
