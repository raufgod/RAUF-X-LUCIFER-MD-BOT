Introduction

RAUF × LUCIFER MD BOT is a free WhatsApp multi-device bot made by RAUF × LUCIFER (Team RAUF × LUCIFER). It adds a large set of commands to a WhatsApp number: music and video downloads, stickers, AI chat, group management, games and much more.

This website is the control room around the bot. It lets anyone link the bot to their own number, create a custom bot with their own name and logo, get help from an AI support agent, learn the commands and contact support. The site owner also has an admin panel.

Quick start

  • Open Link WhatsApp and pick a server (every server connects to the same bot).
  • Choose your country, type your number without the country code or a leading 0 and press Get pairing code.
  • On your phone open WhatsApp, Settings, Linked devices, Link a device, Link with phone number instead and type the 8-character code. The code expires in about a minute.
  • Send .menu in any chat. Every command starts with a dot (you can change that, see Customise).

The website, page by page

  • Home: overview, features and a live demo.
  • Preview: the RAUF × LUCIFER MD BOT OS virtual phone. Open WhatsApp on it and send any command to see the bot answer.
  • Link WhatsApp: pick a server and get a pairing code. Limited to 5 codes per 10 minutes per visitor.
  • Create Bot: set your own bot name, owner name, prefix, links and logo, try a free demo chat, then link your number. You receive a private edit key to change the bot later.
  • Commands: search the featured commands, filter by category and tap a command to copy it. Press Ctrl+K (or the search button) from any page to jump anywhere.
  • AI Support: a support agent that knows the bot. Ask a question or paste an error. It remembers the last 20 messages of your chat.
  • Learn: short guides for common tasks.
  • Docs: this page.
  • Support: buttons for email, Telegram, WhatsApp, the WhatsApp channel and YouTube.
  • Menu, themes and music: the three-line button opens the menu. The palette button changes theme style and colours separately, the bell turns button sounds on or off, the note button controls the background menu song (on by default).

What the bot does

  • Downloaders: songs, videos, TikTok, Instagram, Facebook, Pinterest, MediaFire and more.
  • Stickers and images: make stickers, convert them back, text stickers, effects and AI images.
  • AI: ChatGPT-style chat, DeepSeek, Gemini and others, with memory of the last 20 messages of each chat.
  • Group tools: anti-link, anti-bad-word, welcome and goodbye, tag all, kick, promote, mute and more (the bot must be a group admin).
  • Games and fun: trivia, hangman, tic-tac-toe, truth or dare, jokes, quotes and more.
  • Owner tools: public or private mode, auto reply, bot name, prefix, menu image and status tools.

TechX API commands

These commands use an outside service (techxkamran.onrender.com). The text or link you type after the command is sent to that service, so do not send passwords or private information. If the service is slow or down, the bot says so and you can try again. Each command waits a few seconds between your requests.

  • Anime: .samehadaku (latest, detail, download), .otakudesu (search, ongoing, detail, download), .oploverz (search, ongoing, episode, download), .auratail (search, popular, latest, detail), .anichin, .identifyanime
  • AI: .powerbrainai, .muslimai, .gita, .geminilite, .geminitx, .bibleai, .bard, .flux (picture), .cfchat, .cftranslate, .sentiment, .imgclassify, .embedding
  • Money: .currency (rates, list, convert), .crypto
  • Apps and downloads: .openapk, .an1, .aiodl (one link, many sites)
  • Tools: .subdomains, .voices, .fakedata, .binary2text, .base642text, .shortlink

Send a command without anything after it (for example .currency) to see how to use it. Examples: .currency convert 100 USD INR, .crypto btc, .cftranslate hi Good morning.

AI features

  • Commands: .gpt .gemini .deepseek .asyntai .talkai .notegpt .zonerai .pollinationai .mathgpt and .imagine for images.
  • Each AI remembers the last 20 messages of your chat with it. This memory is kept in the bot server's memory only (about 6 hours without use, and lost on restart). Send .gpt clear (same for the others) to start fresh, or use Clear this chat on the AI Support page.
  • What you type, plus the recent chat for context, is sent to third-party AI services, so do not send passwords or personal documents. Voice to AI needs your own Groq key (.aikey gsk_...; remove it with .aikey remove). See the Privacy Policy.
  • Auto reply (owner): .autoreply on. In private chats the AI answers every message. In groups it answers only when the bot is tagged or someone replies to the bot.

Customise the bot (owner)

  • .setprefix ! changes the command prefix (1 to 3 symbols). Then use !menu. .setprefix . always resets it.
  • .setbotname My Bot and .setownername Name change the names shown in the menu.
  • .settelegram https://t.me/you and .setwebsite https://you.com add links to the menu.
  • .setbotimage (reply to a photo) changes the menu image.
  • .mode private or .mode public decides who can use the bot.

Create your own bot

  • Open Create Bot, fill the details and try the free demo chat. Nothing is sent to WhatsApp in the demo.
  • Pick a server, link your number with the pairing code. Your bot gets its own menu: Developer: RAUF × LUCIFER and Owner: your name, with your links and logo.
  • After linking you get a private edit key (shown once). To change anything later, open Create Bot, use Edit my bot and enter your number and key. The number says which bot it is, the key proves it is yours.
  • Logo: use a direct https link to a JPG, PNG or WEBP picture. The server downloads it once, checks that it is a real image and that the address is public, and uses it as the menu image.
  • The edit key cannot be recovered if lost (only a hash is stored). Contact support if you want a custom bot profile removed.

Troubleshooting

  • Code does not work: it expires in about a minute. Get a new one and type it at once. Check the number and update WhatsApp. WhatsApp allows 4 linked devices.
  • Bot does not reply: check the bot is still in Linked devices, use the right prefix and try .ping. In groups admin commands need the bot to be admin.
  • Download fails: the online service may be busy. Retry after a minute or use a direct link.
  • Still stuck: ask the AI Support page or use the Support buttons.

Privacy and safety

  • The bot is added as a normal linked device, like WhatsApp Web. Remove it any time: WhatsApp, Settings, Linked devices, tap the session, Log out.
  • Never share your pairing code or edit key. Support will never ask for them.
  • The website keeps a few essential items in your browser (your consent record, a random visitor ID for Preview and AI Support, and a page cache). Display choices (theme, colours, sound, zoom, server, country code) are saved only if you allow optional preferences. Use Privacy choices in the footer to see or change this, or to withdraw consent. See the Cookie Policy.
  • Your WhatsApp login keys stay on the bot server, are not shown in the browser and are not part of the automatic backups. Backups hold only small user-data files (settings, warnings, bans and the owner map of linked numbers).
  • To delete your data, unlink the bot in WhatsApp and contact support (see the Privacy Policy). The service is for people 18 and over.
  • Use the bot responsibly: no spam, bulk or unsolicited messages, and follow WhatsApp's rules.
