Questions

Is it safe to link my number?

The bot is added as a linked device, the same way WhatsApp Web works. You can remove it any time from Settings → Linked devices.

The code does not work

Codes expire after about a minute. Tap Get pairing code again and enter the new one straight away. Make sure your WhatsApp is up to date.

Does it cost anything?

No. Linking and using the bot is free.

How do I disconnect it?

Open WhatsApp → Settings → Linked devices, tap the bot's session and choose Log out.
